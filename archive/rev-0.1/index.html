01

EXECUTIVE THESIS

One enterprise experience.
Two interaction contracts.

Process Intelligence与Collaborative Intelligence不是两个独立产品。 它们是同一套Enterprise Intelligence Experience中，人、AI、规则与工具协同工作的两种契约。

FIRST PRINCIPLE

工作可以结构化，也可以开放；交互可以由系统推进，也可以由人主导； 但Goal、Context、Evidence、Decision、Action与Feedback必须共享同一套体验内核。

                  08

                  VISUAL SEMANTICS

                  视觉不是AI装饰，而是工作状态与责任边界的语言。

                  CLARITY我知道正在处理什么

                  Goal · State · Scope

                  TRUST我知道依据和限制

                  Evidence · Source · Confidence

                  CONTROL我知道在哪里干预

                  Preview · Approval · Undo

                  MOMENTUM我看到工作正在推进

                  Plan · Progress · Partial Result

                  CONTINUITY我不需要每次重新开始

                  Context · Memory · History

                  CALM自动化没有制造新焦虑

                  Exception-first · Quiet Defaults

                  SEMANTIC TYPE MEANING VISUAL OBLIGATION
                  Fact可验证事实绑定Source，稳定表达
                  Calculation确定性结果展示Formula或Method
                  Hypothesis候选解释不使用确定性语气
                  Forecast未来判断展示区间、条件和误差
                  Action改变外部状态展示Impact、Permission和Recovery
                  Exception偏离预期路径展示Severity、Owner和Next Step

                  DECISIONS LOCKED

                  这份Charter固定了八个产品级决定。

                  1. 01两种Interaction Contract，不是两套独立产品。
                  2. 02两者共享Kernel、Ontology、Context、Governance与Feedback。
                  3. 03Chat是输入方式，不是默认产品架构。
                  4. 04Work Object与Artifact是企业智能工作的核心载体。
                  5. 05AI自助分析只是Collaborative Intelligence的一部分。
                  6. 06Human Oversight、Evidence、Action与Recovery必须进入体验结构。
                  7. 07Visual Design必须表达语义、状态、风险和控制权。
                  8. 08UIUX进入2027 SOW独立工作流和验收维度。
